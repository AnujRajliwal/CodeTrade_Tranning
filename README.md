# CodeTrade Day 1 Tasks

## 📌 Project Description

This repository contains beginner-friendly Python tasks completed during the CodeTrade AIML Training Program.

These tasks cover important Python concepts such as:
- Variables
- Functions
- Loops
- Conditional Statements
- Lists
- Dictionaries
- User Input
- Random Module

---

# 📂 Tasks Included

## 1. Intro
A simple self introduction program using:
- Variables
- f-strings
- String formatting

---

## 2. Skills Counter
Displays:
- List of skills
- Numbering of skills
- Total skills count

Concepts Used:
- Lists
- enumerate()
- len()

---

## 3. Even or Odd Checker
Checks whether a number is:
- Even
- Odd
- Zero

Concepts Used:
- if-elif-else
- Modulus Operator (%)
- User Input

---

## 4. Tip Calculator
Calculates:
- Tip amount
- Total bill amount

Concepts Used:
- Functions
- Parameters
- Return Statements

---

## 5. Word Frequency Counter
Counts how many times each word appears in a sentence.

Concepts Used:
- Dictionaries
- Loops
- split()
- lower()

---

## 6. Simple Calculator
Performs:
- Addition
- Subtraction
- Multiplication
- Division

Concepts Used:
- Functions
- Conditions
- User Input

---

## 7. Grade Classifier
Assigns grades according to student marks.

Grade Rules:
- A → 90+
- B → 75+
- C → 60+
- D → Below 60

Concepts Used:
- Functions
- Lists
- Dictionaries
- Sorting

---

## 8. Guessing Game
A number guessing game using random numbers.

Concepts Used:
- random module
- while loop
- Conditions

---

## 9. Mini Contact Book
Searches contact details using names.

Concepts Used:
- Lists
- Dictionaries
- Functions
