# AuraHealth Nexus RAG Assistant

## Project Overview

This project implements a Retrieval-Augmented Generation (RAG) system using Google's Gemini API, Sentence Transformers, and ChromaDB.

The system answers questions based on AuraHealth Nexus internal documents by retrieving relevant information from a vector database and providing context-aware responses.

---

## Features

- Document Loading
- Text Chunking
- Semantic Search
- Vector Database Storage
- Retrieval-Augmented Generation (RAG)
- Gemini 2.5 Flash Integration
- Interactive Chatbot
- Source Citation Support
- Evaluation Testing
